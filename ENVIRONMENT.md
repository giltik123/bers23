# Environment setup

Для локальной разработки скопируйте пример окружения в `.env.local` и адаптируйте значения.

Если вы хотите, чтобы Node мог разрешать глобально установленные пакеты (например, `pg`),
добавьте `NODE_PATH`, указывающий на глобальную папку `node_modules`. Пример:

```
# Пример (замените путь на результат `npm root -g` в вашей системе)
NODE_PATH=/usr/local/share/nvm/versions/node/v24.14.0/lib/node_modules
```

Примечание: `.env.local` обычно игнорируется системой контроля версий и не должна
содержать секреты или ключи доступа. Вместо этого используйте этот файл как
инструкцию и создавайте локальный `.env.local` с приватными значениями.
