## Portable *ideas*, implemented as independent code

`PreciseEditPixelLock.ts` proves a **binary, R8-matte, same-geometry, RGBA8 pixel-lock** property:
- pixel matte 0: all four original source bytes preserved exactly;
- pixel matte 255: all four candidate bytes replace source;
- any nonbinary matte/invalid geometry/mismatched byte length: reject, no partial result;
- repeated masked edits preserve all untouched pixels from the previous frame exactly.

The additive `composePreciseEditPatchRgba8` API supports a **bounded, source-registered crop** at integer `{left, top, width, height}` coordinates. The original full-resolution frame is never resized: only the crop's edited pixels are transferred from a separate candidate patch. A patch can be at most 4,194,304 pixels, and output stays in exact source geometry. Both the full-frame and ROI operations require strictly binary mattes; soft edges demand separately specified geometry, alpha and blend policy.

`verifyPreciseEditPixelIntegrityRgba8` is an **independent postcondition** that can inspect any candidate image, including one generated by an external local model: even a single RGB or alpha byte changed outside its declared edit matte is rejected. The auditor reports edit-area size and the number of actually changed authorized pixels. These automated invariants cannot judge realism, body alignment, logo integrity *within* the matte, lighting consistency, or whether the matte has genuine server-side authority.

This is a *simple original BERS research implementation of the general image compositing principle*, NOT an implementation of the Ideogram generative model or its API. It does not synthesize drape, shadows, sleeve boundaries, occlusion mattes, high-resolution texture, or automatically preserve logos **inside** the edited region. No visual-quality claims result from the unit tests alone.

## Highest-fidelity Fashion pipeline proposal

1. Keep the exact current Project image as immutable source identity and do not downsample the whole original for an edit. Work on a bounded high-resolution garment crop with registered geometry and a safety border.
2. Use the admitted F4 geometry/warp + foreground matte to determine **where** garment pixels may change. All masks must be independently resolved against canonical Core source SHA and tenant/Project ownership; browser masks cannot assert authority.
3. Optionally generate a local FASHN Fashion Pack candidate on permitted flat-lay input. **It is not a production-admitted service** until GPU/quality/license evidence and isolation tests pass.
4. Composite candidate pixels only within a bounded, reviewed binary matte using the pixel-lock. A soft, feathered blend is a distinct separately versioned algorithm and must have its own quality tests; do not silently accept intermediate matte values.
5. Judge logo/text/pattern preservation **inside** the edit region against garment reference crops. Pixel-lock outside the mask is necessary but insufficient for fashion fidelity.
6. Apply independent quality checks on representative real photographs: crossed arms, hair over shoulders, side and seated poses, garments with small type, repeating patterns, transparent fabrics, challenging backgrounds and diverse lighting. Record image SHA, reviewer decisions, latency p50/p95, peak RAM/VRAM and exact model/source/weights SHAs. Compare current deterministic F4, local parserless FASHN and any licensed optional editor with the *same inputs*.
7. Do not call Ideogram hosted API under `LOCAL_ONLY`. If a future hosted adapter is admitted: explicit cloud consent, bounded pricing/Billing, server-only credentials, controlled image upload, durable generated bytes (vendor URLs expire), immutable Artifact provenance, preview -> explicit Accept, and no fallback from local failure.

## Evidence thresholds before quality acceptance

- **Zero** changed pixels outside a validated edit mask (automated byte-by-byte postcondition including hidden RGB and alpha), with a source-registered local crop as the default high-resolution edit strategy. This is integrity validation only, not photorealism.
- **Zero** uncaught cross-tenant/stale-source edits; unsafe inputs fail closed.
- Human-reviewed identity (face, hairstyle, hands), fashion logos, text, material and print preservation; explicit failure modes and allowed product scope.
- Real-device latency and peak memory evidence, representative dataset with licensed images, one immutable exact-SHA release comparison artifact.
- Cannot claim 'photorealistic' or 'highest quality' from synthetic fixtures, a vendor benchmark or unit tests.
